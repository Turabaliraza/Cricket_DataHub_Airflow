# Cricket DataHub

An end-to-end cricket data engineering platform built to explore Apache Airflow, automated data pipelines, data processing, databases, APIs, and web-based analytics.

## Project Status

🚧 Under Development

## Planned Technologies

- Apache Airflow
- Python
- Pandas
- PostgreSQL
- FastAPI / Flask
- React
- Docker

## Planned Pipeline

Cricket Data Source
        ↓
Apache Airflow
        ↓
Extract
        ↓
Transform
        ↓
Validate
        ↓
PostgreSQL
        ↓
Backend API
        ↓
React Dashboard

## Planned Features

- Automated cricket data ingestion
- ETL pipelines
- Data validation
- Incremental data loading
- PostgreSQL data storage
- Backend API
- Cricket statistics dashboard
